# ProstoType

Голосовой ввод текста в любое приложение на Маке. Держишь горячую клавишу, говоришь, отпускаешь — текст появляется там, где стоит курсор. Речь распознаётся на устройстве и никуда не уходит.

Здесь лежат только готовые сборки. Нужен Мак с Apple Silicon (M1 и новее).

## Установка

1. Скачай `.dmg` из [последнего релиза](https://github.com/prostotype-app/releases/releases/latest).
2. Открой его и перетащи ProstoType в «Программы».
3. Запусти ProstoType. macOS не откроет его с первого раза: приложение не нотаризовано. Открой «Системные настройки → Конфиденциальность и безопасность» и нажми «Всё равно открыть». Это нужно один раз.
4. Разреши доступ к Микрофону и Универсальный доступ (для вставки текста). Приложение само подскажет, где это сделать.

При первом запуске приложение скачает модель распознавания русского языка.

## Обновления

Установленное приложение само находит новые версии.
